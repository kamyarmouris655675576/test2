تغییرات این نسخه:
- اتصال فرم سفارش و فرم تعمیرات به Web App جدید.
- فرم سفارش اطلاعات را در تب «سفارش‌ها» ثبت می‌کند.
- فرم تعمیرات برای هر پذیرش یک پوشه مستقل با نام مشتری می‌سازد.
- تصاویر JPEG داخل پوشه همان پذیرش ذخیره می‌شوند.
- لینک پوشه همان پذیرش در ستون «پوشه تصاویر» ثبت می‌شود.
- فونت‌های Estedad از فایل‌های داخل همین ZIP بارگذاری می‌شوند.
- لودینگ تا بارگذاری هر سه وزن فونت Estedad پنهان نمی‌شود؛ در صورت خطای فونت، پیام خطا و دکمه تلاش دوباره نمایش داده می‌شود.
- لوگوی سایت به WebP تبدیل شده و حجم آن از حدود ۴۰۱ کیلوبایت به حدود ۵۷ کیلوبایت کاهش یافته است.
- فایل‌های ثابت با Service Worker به‌صورت Cache First ارائه می‌شوند تا بازدیدهای بعدی سریع‌تر باشند.

نحوه انتشار:
1. از فایل‌های فعلی سایت یک نسخه پشتیبان نگه دارید.
2. محتویات ZIP را در ریشه مخزن GitHub Pages جایگزین کنید.
3. پس از انتشار، یک بار سایت را باز کنید و اجازه دهید Service Worker نسخه جدید را نصب کند.
4. برای دریافت نسخه جدید، در صورت نمایش نسخه قبلی از دکمه کوچک بروزرسانی پایین سایت استفاده کنید.

نکته ارسال فرم:
مرورگر به‌دلیل محدودیت CORS پاسخ نهایی Google Apps Script را از درخواست no-cors نمی‌خواند. سایت وضعیت «درخواست ارسال شد» را نمایش می‌دهد، نه تأیید قطعی ثبت سرور. بعد از تست، وجود ردیف در شیت و پوشه تصاویر در Drive باید بررسی شود.

Code.gs داخل ZIP نسخه پشتیبان کد Apps Script فعلی است. اسکریپت منتشرشده را برای اعمال تغییرات سایت نیاز نیست دوباره منتشر کنید؛ URL آن در assets/app.js تنظیم شده است.
